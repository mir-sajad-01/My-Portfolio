# 🚀 My Personal Portfolio

A modern, fully responsive personal portfolio website built with **React.js** and **Tailwind CSS**, designed to showcase my skills, projects, and achievements in a clean and professional way.

---

## ✨ Features

- ⚡ Fast and optimized with Vite
- 📱 Fully responsive on all screen sizes
- 🎨 Clean and modern UI design
- 🧭 Smooth navigation with Navbar
- 👤 Hero & About section with personal intro
- 🛠️ Skills section with tech stack display
- 💼 Projects section with live links
- 🏆 Achievements section
- 📬 Contact section
- 📄 Downloadable Resume

---

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/mir-sajad-01/My-Portfolio.git
```

### 2. Navigate to project folder
```bash
cd My-Portfolio
```

### 3. Install dependencies
```bash
npm install
```

### 4. Run locally
```bash
npm run dev
```

### 5. Build for production
```bash
npm run build
```
